# SDDE-eq-stab
 This repository contains Matlab scripts for the mean-square stability analysis of stochastic delay differential equations (SDDEs), which can be used to generate the figures in the manuscript [Algebraic conditions for second-moment stability boundaries of linear, time-invariant stochastic delay-differential equations](https://arxiv.org/abs/2607.01374)


## Content
- `calculations` scripts for lenghty calculations that generate input data for the figures
- `numerical methods` general purpose algorithms for the second-moment stability analysis of SDDEs
- `figure2.m` analytical first-moment stability map of a scalar SDDE (uses the data generated by `calculations/scalar_moment_stab.m`)
- `figure3.m` analytical second-moment stability maps for a scalar SDDE, considering different multiplicative terms (uses the data generated by `calculations/scalar_moment_stab.m`)
- `figure4.m` stationary correlation functions for a scalar SDDE
- `figure5.m` stationary correlation functions for a scalar SDDE
- `figure6.m` semi-analytical second-moment stability map of a scalar SDDE
- `figure7.m` convergence study of compuational times and discretization errors (uses the data generated by `calculations/scalar_comp_time.m`)
- `figure8.m` semi-analytical second-moment stability map of a scalar SDDE
- `figure9.m` Monte-Carlo simulation of a scalar SDDE that is first- and second-moment stable (uses the data generated by `calculations/scalar_sim_batch_A.m`)
- `figure10.m` Monte-Carlo simulation of a scalar SDDE that is first- and second-moment stable (uses the data generated by `calculations/scalar_sim_batch_B.m`)
- `figure11.m` Monte-Carlo simulation of a scalar SDDE that is first- but not second-moment stable
- `figure12.m` Monte-Carlo simulation of a scalar SDDE that is first- and second-moment unstable
- `figure13abc.m` Monte-Carlo simulation of the inverted pendulum model when it is first- and second-moment stable (uses the data generated by `calculations/osc_sim_batch.m`)
- `figure13d.m` semi-analytical second-moment stability map of the inverted pendulum model
- `figure13e.m` 3D continuation of second-moment stability boundaries of the inverted pendulum model
- `figure15` discretization-based and semi-analytical second-moment stability boundaries for the stochastic turning example (uses data generated by `calculations/turning_moment_stab.m` and `calculations/turning_disc_cont.m`)
- `figure15A.m` Monte-Carlo simulation of the stochastic turning model when it is first- and second-moment stable
- `figure15B.m` Monte-Carlo simulation of the stochastic turning model when it is first- but not second-moment stable
- `figure15C.m` Monte-Carlo simulation of the stochastic turning model when it is first- and second-moment unstable
- `figure16ab.m` second-moment stability map of the stochastic turning process considering different damping values and noise intensities
- `figure16c.m` heatmap of the stationary variance of tool tip oscillations in the stochastic turning model

## Usage
- download the [COCO continuation toolbox](https://sourceforge.net/p/cocotools/wiki/Home/), and execute the `startup.m` script to add it to the Matlab path
- execute each of the scripts `figure*.m` to generate the corresponding figure(s)
