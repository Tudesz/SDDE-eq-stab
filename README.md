# SDDE-eq-stab
Numerical methods for the mean-square stability analysis of stochastic delay differential equations
- this repository contains Matlab scripts for generating the figures in the manuscript [Algebraic conditions for second-moment stability boundaries of linear, time-invariant stochastic delay-differential equations](https://arxiv.org/abs/2607.01374)
- requires the [COCO continuation toolbox](https://sourceforge.net/p/cocotools/wiki/Home/)
